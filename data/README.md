# Локальные данные

Этот каталог намеренно пуст в GitHub-клоне. Локально в нём создаются SQLite
базы, raw API cache и replay artifacts. Пути и порядок восстановления описаны
в [документации данных](../docs/DATA_AND_DATABASE.md).

Не добавляйте сюда токены API, `.dem/.dem.bz2`, выгрузки или SQLite-файлы в git.

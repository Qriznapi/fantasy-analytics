# Документация проекта

Это канонический набор документации. Он описывает текущее состояние кода и
рабочие точки входа, а не исторические эксперименты.

| Документ | Когда использовать |
|---|---|
| [DATA_AND_DATABASE.md](DATA_AND_DATABASE.md) | Схема SQLite, источники, покрытие, сбор и обновление данных. |
| [ANALYTICS_AND_AGENT.md](ANALYTICS_AND_AGENT.md) | Фэнтези-оценки, аналитические поверхности, notebook и agent. |
| [RESEARCH_ARCHITECTURE.md](RESEARCH_ARCHITECTURE.md) | Исследовательская архитектура: данные, ML-модели, RL и контуры оценки. |
| [RNG_ACTOR_CRITIC.md](RNG_ACTOR_CRITIC.md) | Правила эмблем, симулятор, actor-critic, planner и обучение. |
| [REPRODUCIBILITY.md](REPRODUCIBILITY.md) | Установка, проверки и безопасный порядок запуска. |

`reports/` содержит результаты конкретных запусков и не является источником
архитектурной истины. Модели и базы из `models/` и `data/` локальны и могут
отсутствовать в чистой GitHub-копии.
